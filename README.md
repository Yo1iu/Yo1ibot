# Yo1ibot# Расписание МБ-24-08

Telegram-бот с расписанием группы МБ-24-08 (РГУ нефти и газа им. Губкина). Работает в Yandex Cloud Functions (сайт университета доступен только с российских IP). Загрузка — workflow «Загрузить бота в Yandex Cloud», секреты BOT_TOKEN и YC_SA_KEY.

Команды: /today, /tomorrow, /week, /next, /stop.
